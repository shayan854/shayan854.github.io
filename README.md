# Shayan Fallah Kohan - Personal Portfolio

A modern, interactive personal portfolio website built with vanilla HTML, CSS, and JavaScript. This single-page application showcases my journey as a developer, my skills, projects, and interests with a premium, cinematic user experience.

## Features

- Fully responsive design (mobile, tablet, desktop)
- Dark / Light mode with localStorage persistence
- Bilingual support (English / Persian with RTL layout)
- Glass-morphism UI design with animated borders
- Smooth typing animation for role titles
- Interactive timeline showing my journey (2023-2026)
- Animated skill bars with liquid wave effect
- Project showcase with laptop mockup
- Command palette (Ctrl+K) for quick navigation
- Keyboard shortcuts for section jumping
- Konami Code easter egg
- Scroll progress indicator
- Back to top button
- Section navigation dots
- Copy to clipboard for email
- No external dependencies - pure HTML, CSS, JavaScript

## Technology Stack

- HTML5
- CSS3 (custom properties, animations, glass-morphism, flexbox, grid)
- Vanilla JavaScript (no frameworks or libraries)
- Google Fonts (Inter, Vazirmatn)
- Font Awesome icons

## Sections

1. Hero - Name, typing animation, school, avatar with badges
2. About - Personal story, interests, statistics

4. Skills - Programming & tools with animated progress bars

## Customization Guide

### Changing Text Content
Edit the data-i18n attributes or the translations object in the JavaScript section.

### Changing Colors
Modify the CSS variables under :root and [data-theme="light"].

### Adding a New Project
Copy an existing project card in the projects section and update the content.

### Changing Typing Words
Find the words array in the typing() function and update the list.

### Adding a New Language
Add a new key to the translations object and copy the structure.
